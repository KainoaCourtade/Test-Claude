# 🌟 Application Web de Développement Personnel

Une application web moderne et intuitive pour suivre vos objectifs, habitudes et progrès personnel.

## 📋 Fonctionnalités

### 🎯 Gestion des Objectifs
- Créez et suivez vos objectifs personnels
- Catégorisez vos objectifs (Santé, Carrière, Relations, Finance, Apprentissage)
- Marquez les objectifs comme complétés
- Visualisez vos objectifs actifs et complétés

### 📅 Suivi des Habitudes
- Créez des habitudes quotidiennes ou hebdomadaires
- Suivez vos progrès sur les 7 derniers jours
- Visualisez votre taux de complétion
- Calculez votre série de jours consécutifs

### 📝 Journal Personnel
- Écrivez vos pensées et réflexions quotidiennes
- Enregistrez votre humeur du jour (😄 😊 😐 😔 😰)
- Consultez l'historique de vos entrées
- Horodatage automatique

### 📊 Tableau de Bord
- Vue d'ensemble de tous vos progrès
- Citations motivantes quotidiennes
- Statistiques en temps réel
- Graphique de progression hebdomadaire
- Compteur de série de jours

## 🚀 Installation

1. Clonez le repository :
```bash
git clone [URL_DU_REPO]
cd Test-Claude
```

2. Ouvrez `index.html` dans votre navigateur préféré :
```bash
# Sur macOS
open index.html

# Sur Linux
xdg-open index.html

# Sur Windows
start index.html
```

Ou utilisez un serveur local :
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (http-server)
npx http-server
```

## 🎯 Utilisation

### Créer un Objectif
1. Allez dans l'onglet "Objectifs"
2. Cliquez sur "+ Ajouter un objectif"
3. Remplissez le formulaire (titre, description, catégorie)
4. Cliquez sur "Enregistrer"

### Suivre une Habitude
1. Allez dans l'onglet "Habitudes"
2. Cliquez sur "+ Ajouter une habitude"
3. Entrez le nom et la fréquence
4. Cliquez sur les jours pour marquer l'habitude comme complétée

### Écrire dans le Journal
1. Allez dans l'onglet "Journal"
2. Cliquez sur "+ Nouvelle entrée"
3. Écrivez vos pensées
4. Sélectionnez votre humeur
5. Enregistrez votre entrée

### Consulter le Tableau de Bord
- Le tableau de bord se met à jour automatiquement
- Affiche vos statistiques globales
- Montre votre progression hebdomadaire
- Propose des citations motivantes

## 🔒 Confidentialité

Toutes vos données sont stockées localement dans votre navigateur via LocalStorage. Aucune donnée n'est envoyée à un serveur externe. Vos informations restent privées et sous votre contrôle.
